# FFT Interactive Web App

This repository contains a minimal Jupyter Notebook FFT demo that runs on:
- **Binder** (normal Jupyter Notebook)
- **Voila** (turns notebook into a web app)

## Launch in Binder
Click this once the repo is live:
[![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/JaimeOrtega86/IntroPhotonics-2DFFT/main)

## Launch as a Web App (Voila)
(works on mobile!)
Vertical version: 

https://mybinder.org/v2/gh/JaimeOrtega86/IntroPhotonics-2DFFT/main?urlpath=voila%2Frender%2FpolishedFFT.ipynb

2x2 panel version:
