# FFT Interactive Web App

This repository contains a minimal Jupyter Notebook FFT demo that runs on:
- **Binder** (normal Jupyter Notebook)
- **Voila** (turns notebook into a web app)

## Launch in Binder
Click this once the repo is live:
[![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/<YOUR_USERNAME>/<YOUR_REPO>/main)

## Launch as a Web App (Voila)
(works on mobile!)
https://mybinder.org/v2/gh/<YOUR_USERNAME>/<YOUR_REPO>/main?urlpath=voila%2Frender%2Fminimal_fft_app.ipynb
